# Origin

This pack was written as an original set of operational instructions for AyXDesigns WordPress delivery work.

Its maintained source inputs are the portfolio's own delivery blueprint, portfolio-state record, and tools-and-code notes. Those documents describe local conventions, observed failure modes, acceptance criteria, and release practice. All skill instructions in this repository are newly authored for this pack.

The pack also checks current official WordPress project guidance when it affects compatibility or release decisions. Relevant maintained references include WordPress core development, Gutenberg, Create Block Theme, and Plugin Check. This repository does not redistribute their code or documentation text. Any future inclusion of upstream code or assets requires a separate licence-compatibility review and the required notices.

From version 0.2.0 the pack is released under the MIT licence. Third-party products, plugins and services are named only to describe options; the pack is not affiliated with or endorsed by them.

Before a public release, maintainers must review every changed file for customer information, credentials, production URLs, personally identifiable information, and material copied from outside this repository.
