# Content brief template

One brief per page. A writer who has never spoken to the client should be able to produce a good draft from it, and a reviewer should be able to check the draft against it.

| Field | Value |

| Page type | Guide / service / comparison / product / case study / FAQ hub / other |

| Cluster and role | `<cluster name>`: hub / support |
| Brief by, date | `<role>`, `<YYYY-MM-DD>` |

- **Visitor question or task (their words):** "`<...>`"

## 5. Outline

Descriptive headings, one idea each, in the order the reader needs them.

```text
H1: <states the page's purpose plainly>
  Intro: direct answer + who this is for
  H2: <...>
  H2: <...>
    H3: <...>
  H2: Next step / how we can help
```

Format notes: tables for comparisons and prices (as HTML text, not images); steps as numbered lists; define terms on first use.

## 9. Acceptance criteria

- [ ] Main question answered in the first paragraph
- [ ] Every question in section 3 answered
- [ ] Every factual claim has a source or first-hand basis; no `<needs source>` left
- [ ] Author and, if required, reviewer named on the page
- [ ] Links in section 6 added, including inbound links on other pages
- [ ] Title and H1 unique on the site
- [ ] Next step visible without scrolling past the whole page
- [ ] Reads correctly with images off
