# WordPress SEO discovery brief

Use for a new site, redesign, service expansion, or material information-architecture change. This is an editorial and technical discovery skill, not a promise of rankings or a request to create thin keyword pages.

## Build the page map

For every proposed indexable page, record:

- visitor/search intent and unique page purpose;
- audience and geography only where relevant;
- primary next step and conversion owner;
- parent, breadcrumb, and contextual internal-link relationships;
- content owner, evidence source, review date, and freshness trigger;
- index, noindex, redirect, or canonical decision.

Prefer one authoritative page per intent. Do not create location or keyword variants without genuine unique usefulness, local evidence, and ownership.

## WordPress handover

State which WordPress surface owns each field: page/block content, pattern, taxonomy, theme setting, plugin setting, or approved structured source. Assign exactly one owner for titles, descriptions, canonicals, sitemaps, robots directives, redirects, social metadata, and structured data.

Use specialist research only where it changes the plan: local/service-area validation, full strategy, content clusters, or high-value editorial briefs.

## Output

Produce a page map, indexation map, content brief set, internal-link plan, ownership matrix, evidence gaps, and measurable launch baseline plan.
